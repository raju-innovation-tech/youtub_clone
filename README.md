# 🎥 YouTube Clone (Frontend Project)

A responsive **YouTube Clone UI** built using **HTML, CSS, and JavaScript**. This project focuses on recreating the core layout of YouTube such as the **Navbar, Sidebar, Video Grid, and Video Card UI**. Perfect for beginners learning frontend web development.

## 📌 Features

* ✅ Responsive Navigation Bar (Left / Middle / Right sections)
* ✅ Sidebar with shortcut links & subscriptions
* ✅ Video listing grid (thumbnail + channel info)
* ✅ Clean and modern YouTube-like UI
* ✅ Simple and beginner-friendly structure

## 🛠️ Technologies Used

* **HTML5** – Page structure
